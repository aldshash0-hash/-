# العكريشي – موقع يعمل على GitHub Pages (مع لوحة مدير ورفع فيديو من الهاتف)

كل شيء داخل مستودع GitHub واحد: الموقع، والكورسات، والفيديوهات. لا خادم ولا Firebase. تدير الموقع من الموقع نفسه، ويتحدث المستودع تلقائيًا عند الضغط على «نشر».

## التركيب (مرة واحدة)
1. أنشئ حسابًا على github.com، ثم **New repository**: سمّه `alakrishi` واجعله **Public** (الاستضافة المجانية تحتاجه؛ المحتوى المدفوع مشفّر فلا خطر).
2. اضغط «uploading an existing file» وارفع `index.html` و`data.json` و`README.md`، ثم **Commit changes**.
3. من Settings ← **Pages**: Source = Deploy from a branch، Branch = `main` / `(root)` ثم Save. بعد دقيقة يظهر رابط موقعك: `https://اسمك.github.io/alakrishi/`.
4. أنشئ **رمز الدخول (Token)** لتتحكم بالموقع من المتصفح:
   - GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
   - Repository access: **Only select repositories** ← اختر `alakrishi`.
   - Permissions ← Repository permissions ← **Contents: Read and write**.
   - اختر أطول مدة انتهاء، ثم Generate وانسخ الرمز (يبدأ بـ `github_pat_`) واحتفظ به سرًّا.

## الدخول كمدير ورفع فيديو من الهاتف
1. افتح موقعك ← «دخول المدير» أسفل الصفحة.
2. المستودع يُملأ تلقائيًا. الصق الرمز، واختر **كلمة سر للمدير من 12 حرفًا فأكثر** (أول مرة تكتبها مرتين). *احفظها جيدًا؛ لا يمكن استرجاعها.*
3. «الكورسات والدروس»: أنشئ كورسًا، ثم درسًا، واختر **الفيديو من معرض هاتفك** (حتى 50 ميجا) و/أو ملزمة PDF، ثم «حفظ الدرس».
4. «أكواد التفعيل»: أنشئ كودًا لكل طالب وأرسله له بعد التحويل.
5. «النشر» ← **نشر الآن**. انتظر حتى تظهر «تم النشر ✓»، وبعد دقيقة إلى دقيقتين يراها الطلاب.

## كيف يعمل الدفع والحماية
- الطالب يحوّل المبلغ إلى الرقم في الإعدادات ويرسل الصورة على واتساب، فتعطيه الكود.
- الدروس المجانية عامة. الدروس المدفوعة **مشفّرة** (النص والأسئلة والفيديو والملزمة) ولا تُفتح إلا بالكود الصحيح.
- بيانات المدير (الأكواد والمفاتيح) محفوظة في `source.enc` **مشفّرة بكلمة سرك**؛ لهذا يجب أن تكون طويلة وقوية.

## حدود وتنبيهات
- الفيديو الواحد حتى 50 ميجا (اضغطه 720p). للفيديوهات الأطول استخدم رابط يوتيوب «غير مدرج» في خانة الرابط.
- حدود GitHub: الموقع المنشور حتى 1 جيجا تقريبًا، ونقل بيانات شهري محدود، فهو مناسب لعدد متوسط من الطلاب.
- من فُعّل له كورس قد يسجّل الشاشة أو يشارك كوده؛ أنشئ كودًا لكل طالب. حذف الكود لا يسحب ما شاهده بالفعل.
- **الرمز (Token) يمنح التحكم الكامل بموقعك**: لا تشاركه، ولا تفعّل «تذكّر الرمز» على جهاز غير جهازك. إن ضاع فألغِه من GitHub وأنشئ غيره.
- كلمة سر المدير لا تُسترجع، ولا يمكن أن تكون `ABCDEFG`: المستودع عام، فأي كلمة قصيرة يمكن كسرها وكشف الأكواد.
- لا حسابات للطلاب؛ الأكواد والنتائج تُحفظ على جهاز كل طالب.
