# العكريشي – موقع ثابت بكود تفعيل (بلا خادم)

لا يوجد Firebase ولا قاعدة بيانات. الموقع ملفات ثابتة تُنشر مجانًا (GitHub Pages أو Netlify أو Cloudflare Pages).

## الملفات
- `index.html` الموقع الذي يراه الطلاب.
- `data.js` بيانات الكورسات (يُولَّد من أداة المدير). الدروس المدفوعة فيه **مشفّرة**.
- `admin.html` أداة المدير. تُفتح من رابط «دخول المدير» أسفل الموقع (كلمة السر ABCDEFG)، أو بالنقر المزدوج من جهازك.

## كيف تعمل
1. افتح `admin.html` (من الموقع أو من جهازك)، أنشئ كورسًا وأضف دروسه (فيديو يوتيوب «غير مدرج» + ملزمة + أسئلة)، وحدّد الدرس المجاني إن أردت.
2. من تبويب «أكواد التفعيل» أنشئ كودًا لكل طالب.
3. من تبويب «النشر» نزّل `data.js` وارفعه إلى موقعك بدل القديم، ونزّل `source.json` واحتفظ به عندك فقط.
4. الطالب يحوّل المبلغ إلى الرقم المكتوب، ويرسل الصورة على واتساب، فتعطيه الكود ويكتبه في صفحة الكورس فتُفتح الدروس.

## النشر
- GitHub Pages: ارفع `index.html` و`admin.html` و`data.js`، ثم Settings ← Pages ← Deploy from branch. الاستضافة المجانية تحتاج غالبًا مستودعًا عامًا، ولا مشكلة لأن المحتوى المدفوع مشفّر. ولو أردت مستودعًا خاصًا فاستخدم Netlify أو Cloudflare Pages.
- لا ترفع `source.json` أبدًا (فيه نصوص الدروس المدفوعة وأكواد الطلاب). الملف `.gitignore` يمنع ذلك.
- كلمة سر المدير ABCDEFG **شكلية فقط**: هي مكتوبة داخل الملف ويستطيع أي أحد تجاوزها، ولا تحمي شيئًا. لا يستطيع أحد تغيير موقعك لأن النشر لا يتم إلا برفع `data.js` من حسابك على GitHub. لذلك فعّل التحقق بخطوتين عليه. ولا تستخدم هذه الكلمة لتشفير المحتوى لأنها سهلة التخمين.
- فعّل التحقق بخطوتين على حساب GitHub، فمن يملك حسابك يملك موقعك.

## حدود هذا الأسلوب (اعرفها قبل الإطلاق)
- لا حسابات للطلاب. أكواد التفعيل ونتائج الاختبارات تُحفظ في متصفح كل طالب فقط.
- لا يمنع النظام الطالب من مشاركة كوده؛ أنشئ كودًا مستقلًا لكل طالب لتعرف مصدر أي تسريب واحذفه ثم انشر `data.js` جديدًا.
- من فُتح له كورس قد يحتفظ برابط الفيديو؛ استخدم فيديوهات «غير مدرجة».
- الفيديو من يوتيوب فقط (لا رفع مباشر من الهاتف). عناوين الدروس المدفوعة ظاهرة للجميع، أما روابطها وأسئلتها فمشفّرة.
- لا يوجد رمز على البريد؛ حماية موقعك هي حماية حساب GitHub وجهازك.
